山梨地域バスロケーション（リアルタイム専用版）
================================================

PHP・ログ保存・運用履歴・次便予測・運行日区分・バス停API取得を外し、
APIから取得した現在のバス位置だけを地図に表示。

含まれる主なファイル:
- index.html
- js/app.js
- css/style.css
- data/vehicle.csv
- img/*

重要：ブラウザーから https://api.buskita.com/get-buses に直接POSTします。
API側がCORSを許可していない場合、ブラウザーのセキュリティ制限で取得できません。
その場合、PHPを使わないという条件のままでは、API提供元のCORS対応か、利用許可された別の公開API/プロキシが必要です。
CORSエラーが出ても、PHPファイルを戻すのではなく、まずブラウザー開発者ツールのConsole/Networkで確認してください。
githubはPHPの読み込みができないため一時的に公開するものです。そのためログはとっていません。PHP・ログ保存・運用履歴・次便予測・運行日区分・バス停API機能は本試行時に付け加えます。
